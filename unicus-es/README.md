# ¡Comencemos!

Aquí encontrarás toda la información que necesitas para implementar la solución de validación de identidad de Unicus. Conoce todos los detalles de configuración, actualización y personalización para tu empresa. Intégrala de forma fácil, rápida y segura.

## ¿Cómo puedes empezar?

Elige la integración que mejor se adapte a tus procesos:

1. En una página web, con el botón de [Unicus Web SDK 5.0](sdk-web-v5/overview.md). Si quieres ir directo al código, empieza por el [Inicio rápido](sdk-web-v5/quick-start.md) y la [Lista de integración](sdk-web-v5/integration-checklist.md).
2. En una aplicación móvil, con el SDK de [Flutter](mobile-sdk/flutter-integration.md), [Android](mobile-sdk/android-integration.md) o [iOS](mobile-sdk/ios-integration.md).
