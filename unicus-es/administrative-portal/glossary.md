# Glosario

| Término | Significado |
| --- | --- |
| **Transacción** | Una verificación de una persona: un enrolamiento, una verificación o una prueba de vida. Se identifica con su **TID**. |
| **TID** | Identificador único de la transacción. Lo reciben tu página (eventos), tu backend (webhook) y lo ves en el portal. |
| **Enrolamiento** | La primera vez que Unicus registra a una persona: su rostro y su documento. |
| **Verificación** | Comprobar que quien está frente a la cámara es una persona ya enrolada. |
| **Prueba de vida** | Comprobar que hay una persona real frente a la cámara, y no una foto, un video o una máscara. |
| **Cola de revisión** | Enrolamientos cuyo rostro coincide con otros de tu empresa y esperan una decisión de tu equipo. |
| **Flujo** | Los pasos que hace la persona en una verificación. Se compone y publica en el portal. |
| **Caso de uso** | El tipo de transacción al que se asigna un flujo: enrolamiento, verificación, prueba de vida o estimación de edad. |
| **Flujo por defecto / variante** | El flujo que corre cuando tu integración no pide otro, y los flujos alternativos que pide por su identificador. |
| **Versión** | Cada publicación de un flujo. No cambia después de publicada. |
| **ID de la compañía (Customer Token)** | Identificador público de tu empresa para el botón y los SDK móviles. |
| **API key** | Credencial secreta de tu backend para los endpoints de servidor. |
| **Webhook** | La URL de tu backend a la que Unicus envía el resultado de cada transacción. |
| **Unicus Link** | Un enlace de verificación que le envías a la persona en lugar de integrar el botón. |
| **Constancia** | El PDF con el resultado de una transacción, verificable en **Verificar constancia**. |
| **Datos personales** | Las fotos y los datos leídos del documento. Solo los ve quien tiene el permiso. |
| **Credenciales de prueba** | Credenciales que entrega Tekbees para probar con el flujo real sin mezclar las pruebas con las transacciones reales. |
