# Let's get started!

Here you will find all the information you need to implement the Unicus identity validation solution. Learn all the details of configuration, upgrade and customization for your company. Integrate easily, quickly and securely.

## How can you get started?

Choose the integration that best fits your processes:

1. On a web page, with the [Unicus Web SDK 5.0](sdk-web-v5/overview.md) button. To go straight to the code, start with the [Quick start](sdk-web-v5/quick-start.md) and the [Integration checklist](sdk-web-v5/integration-checklist.md).
2. Without a page of your own, by sending the user a verification link with [Unicus Link](sdk-web-v5/unicus-link.md).
3. In a mobile app, with the [Flutter](mobile-sdk/flutter-integration.md), [Android](mobile-sdk/android-integration.md) or [iOS](mobile-sdk/ios-integration.md) SDK.

Already integrated with Web SDK 4.x? Read [Migration from Web SDK 4.x](sdk-web-v5/migration-from-v4.md).
