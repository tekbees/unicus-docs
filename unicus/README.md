# Let's get started!

Here you will find all the information you need to implement the Unicus identity validation solution. Learn all the details of configuration, upgrade and customization for your company. Integrate easily, quickly and securely.

## How can you get started?

There are two options to start implementing the solution, review them and choose the one that best suits your processes.

1. Use our implementation method with [Unicus SDK](sdk-web/unicus-button.md).
2. Service implementation using [Unicus link](sdk-web/unicus-link.md).
