# Integration overview

Unicus offers you the flexibility to customize the look and feel of the verification flow your users will access, you can include your logo and your organization's colors by simply accessing the settings from the  [administration panel](https://app.idunicus.com/).

### Unicus Button

With Unicus Button it is possible to implement the verification of your customers by simply adding the script to your web page or application. Unicus Button is compatible with any web technology.

To learn more [Unicus Button](https://dev.idunicus.com/sdk-web/integracion/unicus-button) Integration

![Default (blue) option](<../.gitbook/assets/Screenshot from 2020-11-10 08-49-26.png>)

### Unicus Link

Unicus Link allows your users to verify themselves by simply entering a url that can be sent via Whatsapp, email, text message, etc.

To learn more [Unicus Link](https://dev.idunicus.com/sdk-web/integracion/unicus-link) Integration
